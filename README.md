# KTF Elmi Monitorinq — Windows tətbiqi

Kimya texnologiyaları fakültəsi müəllimlərinin Scopus statistikası: məqalə, istinad, jurnal kvartili, h-index, kafedraların liderləri. AZ / EN / RU.

## Quraşdırma faylını yükləmək
Sağ tərəfdə **Releases** → ən son versiya → `KTF_Elmi_Monitorinq_Setup.exe`.
Quraşdırma: Next → Install. "Windows protected your PC" görünsə: **More info → Run anyway**.
Python və ya başqa proqram lazım deyil.

## Müəllim siyahısı
`Sənədlər\KTF Elmi Monitorinq\muellimler.xlsx` — tətbiqdəki **Müəllim siyahısı (Excel)** düyməsi bu faylı açır.
Dəyişib yadda saxlayın, sonra tətbiqdə **Yenilə** basın.

## Yeni versiya
Faylları dəyişib `main`-ə yükləyin — GitHub Actions yeni quraşdırma faylı yığır və Releases-ə qoyur.
